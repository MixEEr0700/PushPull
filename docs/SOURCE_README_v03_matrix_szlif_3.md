# PushPull v0.3 Matrix · szlif 3

Zmiana względem szlifu 2: karta ćwiczenia i historia pokazują ostatni wynik w skrócie, gdy wszystkie serie mają jednakową liczbę powtórzeń i ciężar. Jeżeli przynajmniej jedna seria się różni, pokazują osobne wiersze z każdą serią. Dla zapisów starszych, bez tablicy serii, nie odtwarzamy brakujących serii. Kliknięcie ołówka przy wyniku z historii prowadzi do szczegółowego edytora sesji w kalendarzu.

Pozostały układ Matrix, kalendarz, rotacja, notatki oraz moduł statystyk bez zmian.

To szkic lokalny, nie aplikacja produkcyjna. Parametry planu wymagają sprawdzenia z dokumentem trenera.
